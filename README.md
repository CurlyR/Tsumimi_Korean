# 츠미미 타임 ~미치도록 사랑해~ 본편 한국어 패치

**번역 : 컬리비**

## 설치

1. 게임을 종료합니다.
2. ZIP을 풀고 `KoreanPatch` 폴더를 `arc0.dat`가 있는 게임 설치 폴더 안에 넣습니다.
3. `KoreanPatch/InstallKoreanPatch.cmd`를 실행합니다.
4. 게임을 실행합니다.

## 업데이트 후 재설치

설치기는 현재 게임 버전이나 설치된 게임 파일의 원본 해시를 비교하지 않습니다. 업데이트 후에도 같은 설치 파일을 실행할 수 있습니다. 배포된 패치 파일 자체의 손상 여부만 확인합니다.

이 패치는 수정된 게임 파일을 덮어쓰는 방식입니다. 버전 제한이 없다는 것이 모든 향후 업데이트와의 호환성을 보장하는 것은 아닙니다. 파일 구조나 실행 코드가 크게 바뀌면 패치를 다시 작업해야 합니다.

## 복원

게임을 종료한 뒤 `RestoreKoreanPatch.cmd`를 실행하면 **가장 최근 패치 설치 직전 상태**로 돌아갑니다. 백업은 게임 폴더의 `KoreanPatchBackup`에 설치 시각별로 저장됩니다. 이미 패치된 상태에서 재설치했다면 해당 백업도 이전 패치 상태입니다.

설치·복원은 패치 대상 파일에만 적용되며 저장 데이터는 변경하지 않습니다.

## 작업 범위

- 본편 대사 4,038개와 UI·SNS·추리 문구 1,193개 한국어 번역.
- 힌트·정답·지명·인물 호칭의 번역을 연계하고 영어 언어 슬롯에도 같은 번역 적용.
- 한국어 픽셀 폰트 적용 및 한글 글자 폭 처리.

## 검수

번역 데이터 누락, 제어문자, 한글 폰트 글리프, 아카이브 및 번들 구조, 설치·복원을 기술적으로 확인했습니다.
수정 사항을 전달할 때 이미지 파일명 또는 장면·대사와 화면 캡처를 함께 남기면 해당 부분을 확인하기 쉽습니다.

## 폰트 및 동봉 파일

NeoDunggeunmo 기반 한국어 픽셀 폰트를 사용합니다. 관련 라이선스는 `licenses` 폴더에 있습니다.

| 파일 | 용도 |
| --- | --- |
| `InstallKoreanPatch.cmd` | 한국어 패치 설치 |
| `RestoreKoreanPatch.cmd` | 가장 최근 설치 직전 상태 복원 |
| `Patch.ps1` | 설치·백업·복원 처리 |
| `manifest.json` | 패치 파일 목록과 패치 파일 무결성 정보 |
| `payload` | 적용할 게임 파일 |
| `licenses` | 폰트 라이선스 |
